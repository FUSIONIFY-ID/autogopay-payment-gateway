# AutoGoPay extension

For an AutoGoPay integration request, use the bundled autogopay-payment-gateway agent skill under skills/autogopay-payment-gateway/SKILL.md and load the relevant provider references. Preserve the user's project stack. Keep secrets server-side, never ask for API keys or PINs in chat, and distinguish mocked verification from live payments. This extension provides integration guidance; it does not authorize real payments or transfers. For unrelated work do not activate payment integration.
