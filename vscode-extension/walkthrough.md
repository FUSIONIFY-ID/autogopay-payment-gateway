# AutoGoPay dalam proyekmu

1. Buka folder proyek yang kamu percaya.
2. Pilih **AutoGoPay: Pasang Skill ke Proyek**.
3. Pilih AI coding agent yang digunakan.
4. Salin prompt integrasi dan tempel ke AI tersebut.
5. Isi API key hanya di backend aplikasi, hubungkan provider, dan uji pembayaran.

Extension memasang panduan. Ia tidak memanggil payment API, menyimpan API key, menjalankan transfer, atau membuat pesanan lunas.
